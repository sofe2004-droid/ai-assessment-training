# AI·디지털 기반 평가 설계와 실행 — 연수용 웹앱

중등 교원 3차시 연수(교안 설명 + 활동지 작성 + Word 결과 문서 저장)를 위한 정적 웹앱입니다.
빌드 도구 없이 HTML/CSS/JS로 만들었고, Vercel에 그대로 배포됩니다.

## 참여자 사용법
1. 배포 주소에 접속해 성명·소속을 입력하고 **연수 시작하기**를 누릅니다.
2. 왼쪽 목차 또는 **← 이전 / 다음 →** (키보드 ← →)로 교안 슬라이드를 넘깁니다.
3. 활동 슬라이드에서는 슬라이드 아래 **입력 패널**에 활동지 내용을 작성합니다. 입력은 **자동 저장**됩니다.
4. 프롬프트 활동에서는 **프롬프트 복사**로 생성형 AI(ChatGPT·Claude·Gemini 등)에 붙여 넣고, AI 응답과 내가 고친 최종본을 패널에 적습니다. (앞 단계 입력이 프롬프트에 자동으로 들어갑니다.)
5. 연수가 끝나면 왼쪽 아래 **결과물 문서 저장**에서 **Word(.docx)** 를 내려받습니다. **백업 파일(.json)** 도 함께 저장해 두세요.

> 입력 내용은 서버로 전송되지 않고 **각자 기기의 브라우저(localStorage)** 에만 저장됩니다. 브라우저 방문 기록/사이트 데이터를 지우면 사라질 수 있으니 백업 파일을 저장하세요. 학생 이름·학번 등 개인정보는 입력하지 마세요.

## 10명 연수를 위한 개인 활동 전환
| 원래 활동 | 이 웹앱 |
|---|---|
| 1차시 활동 2 · 조의 고민 묶기 | 내 고민을 5분류에 나누어 적기 + 핵심 질문 공식 4칸 |
| 1차시 조 안 사례 공유 | 보충 활동자료 사례 3개를 앱에서 보고 개인 판단 |
| 2차시 설계안 교차 검토(2인) | 개인 자기 점검(좋은 점 1 + 수정 제안 1) |
| 3차시 같은 학생 자료 채점 후 옆 사람과 비교 | 공통 사례(학생 A/B)를 개인 채점 → 루브릭 자기 재검토 |

## 강사 설정 (`js/config.js`)
- `date`: 문서 표지에 넣을 연수 일자 (비우면 저장하는 날짜)
- `surveyUrl`: 마지막 슬라이드에 표시할 만족도 조사 링크
- `storageKey`: 저장소 키. 회차별로 입력을 분리하려면 값을 바꿉니다.

## 구성
```
index.html
css/app.css
js/config.js      연수 설정
js/store.js       자동 저장·백업
js/worksheet.js   활동지 구조 (활동·필드·필수 항목)
js/slides.js      교안 슬라이드 데이터 (71장)
js/cases.js       연수용 가상 사례 (컵 감축·학생 A/B 등)
js/app.js         화면·라우팅·입력 패널
js/export-docx.js Word 문서 생성
vendor/docx.iife.js  docx 라이브러리 (MIT)
```

## 배포
Vercel에서 이 저장소를 Import(Framework Preset: `Other`, Build/Output 비움)하면 됩니다. `main`에 push하면 자동 배포됩니다.
로컬 확인: 폴더에서 `python -m http.server 5180` 후 `http://localhost:5180` (또는 `index.html`을 직접 열어도 동작).

## 참고
- 교안 슬라이드는 HTML로 재구성했으며, 교안의 표기 오류(6·12·18·36쪽)는 앱에서 바로잡았습니다.
- 연수용 사례의 수치·학생 발언·AI 응답은 모두 가상입니다.
