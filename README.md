# AI·디지털 기반 평가 설계와 실행 — 연수용 웹앱

중등 교원 3차시 연수(교안 설명 + 활동지 작성 + Word 결과 문서 저장)를 위한 정적 웹앱입니다.

- 빌드 도구 없는 정적 사이트(HTML/CSS/JS)입니다.
- 입력 내용은 각자 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.
- 학생 이름·학번 등 개인정보는 입력하지 마세요.

## 배포
Vercel에서 이 저장소를 Import하면 됩니다. Framework Preset은 `Other`, Build Command와 Output Directory는 비워 둡니다. 이후 `main`에 push하면 자동 배포됩니다.

> 개발 중입니다.
